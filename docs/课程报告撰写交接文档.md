# EmbodiedEdu 课程报告撰写交接文档

本文供课程小组成员及协助撰写的 Agent 使用。目标是依据 GitHub 仓库中的实际代码，完成一份突出人机交互设计、覆盖全部教学场景、证据清晰的课程报告。报告题目暂定为《EmbodiedEdu：面向课堂教学的多模态具身交互平台》，可按课程要求调整。

## 一、项目背景与撰写约定

EmbodiedEdu 是一个面向课堂的多模态交互工作台。它将手势、身体姿态、语音、鼠标和键盘用于课件、白板及多个学科的教学实验，帮助教师演示、学生操作和探究。项目包含 2 个课堂工具与数学、物理、化学、语文、生物、美术、地理七个学科的 13 个实验，另有平台级具身教学智能体「灵犀」（试点接入分子搭建与函数绘图两个场景）。

报告的主线建议为：**课堂中的问题和用户需求 → 交互设计 → 系统实现 → 场景应用 → 测试评价 → 总结反思**。重点解释设计决策及其对使用体验的影响，避免只罗列技术栈或界面按钮。

### 使用仓库的约定

1. 克隆或打开组长提供的 GitHub 仓库，记录所阅读的分支、提交号和日期。仓库可能持续更新，以下路径和描述以本次交接时的项目为基础，最终以报告对应版本的代码为准。
2. 先读 `README.md`、`package.json`、`src/App.tsx`、`src/core/` 和 `src/scenes/registry.ts`，再根据分工阅读对应场景、算法及测试。`docs/plans/` 中的设计文档可提供背景，但计划不等于最终实现。
3. 每项事实尽量核对实现、界面和测试；代码注释及 README 是线索，不应自动当成实测结论。若文档、代码、运行结果不一致，记录差异并以对应版本实际行为为准。
4. 不编造访谈、问卷、用户人数、实验结果、准确率、教学成效或参考文献。未开展的工作写成“拟开展的评价方案”，不要写成已经完成。
5. 区分自动化测试、实际设备测试和用户评价。测试通过不能直接证明真实课堂中的可用性或教学效果；教学模型的近似也不应表述为精密科学测量。
6. 报告中的截图、数据、引用需标注来源或采集条件；外部学术概念和技术资料应查证原始出处。不要读取、复制或提交 `.env` 中的密钥。

#### 3.8 智能体交互设计：具身教学智能体「灵犀」
说明"感知—决策—行动"闭环如何落实为交互设计：感知来源（会话快照、总线语义事件、空闲时长、学生提问输入）；分层决策（本地规则策略负责介入时机与演示选择，LLM 负责口语化解说与自由问答，且不产生动作）；行动方式（经场景适配器在场景内真实执行演示脚本）。重点分析四个设计决策：触发冷却避免打扰、演示前需学生确认（避免覆盖学生成果）、学生任何操作可随时打断演示（智能体不与学生抢画面）、未配置 LLM 时的模板文案降级。另请分析**"问题→就地修复"模式**：感知到学生作品出问题时（分子超价、陶坯造型不达标、函数拟合不符），智能体先以身体动作指向出事对象（选中高亮、键数徽标），经确认后在作品上执行最小修复并重新判题——这是闭环闭合在学生自己成果上的关键设计，也是具身叙事的核心案例。**分子场景的"闭环搭建器 + 可见的手"是具身智能思想最完整的展示，建议单列分析**：(a) 世界模型——行动前用确定性判题内核预测结果（键数/合法性），行动后核对预测与实际，不符即解释并重规划（"预测-行动-观察"与任务卡教学生的方法论同构）；(b) 扰动鲁棒——学生插手通过软打断（适配器 disturb 钩子）触发"暂停-重感知-自适应继续"，而非取消演示；(c) 身体可见性——画布内虚拟手使每个动作"手先到、再捏合、再执行"，"推氢回弹"实验用身体演示几何约束。阅读 `src/core/agent/`（types/brain/controller/llm/useAgentRuntime）、`src/ui/agent/`、`src/scenes/molecule/agentAdapter.ts`、`src/scenes/molecule/buildPlanner.ts`、`src/scenes/functions/agentAdapter.ts`、`src/scenes/art/shapeFix.ts`。

**阅读材料**：`src/App.tsx`、`src/core/interaction.ts`、`src/core/services.tsx`、`src/core/useHandInput.ts`、`src/core/usePoseInput.ts`、`src/core/useVoiceInput.ts`、各场景的手势/语音策略。

### 5. 教学场景与交互设计

本章覆盖全部场景。每个小节建议按相同结构写：**教学目标与概念 → 用户操作及输入方式 → 系统可见反馈 → 任务或验证方式 → 使用条件与局限**。每个学科至少给一个具体操作例子；可根据篇幅选择截图，不必让每一节篇幅相同。具体任务、阈值和手势均需核对对应实现。

#### 5.1 课堂工具
**5.1.1 课件控制：挥手翻页与激光笔**：介绍应用内课件、本机 PowerPoint、挥手/按键翻页、激光笔及反馈；说明外部 PowerPoint 窗口中激光点的显示边界。阅读 `src/scenes/slides/` 和 `server/powerpoint.ts`。

#### 5.2 数学实验
**5.2.1 空间几何：正方体截面探究**：说明切面位置、方向调整，三维立方体与二维截面的对应，参与面高亮，以及预测、寻找形状和快照对比任务。阅读 `src/scenes/geometry/`。

**5.2.2 函数绘图：用身体绘制和识别函数**：说明画布坐标与函数变量的对应、采样和拟合、拟合曲线反馈，以及预测、画函数和曲线对比任务；将测试条件和真实手势体验区分。阅读 `src/scenes/functions/`。
