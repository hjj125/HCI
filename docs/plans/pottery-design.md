# 美术实验一 · 陶艺工坊（art-pottery）设计方案

状态：已实现。本文档记录设计决策，供课程报告引用。

## 1. 定位与教学目标

**虚拟陶轮上的拉坯与彩绘**，对准美术课程素养：造型能力（拉坯塑形）、对称与重复（纹样设计）、色彩运用（传统釉色）。身体即雕塑工具——延续平台"具身映射学习对象本身"的设计语言。铁律照旧：确定性内核可单测、手势词汇零新增、任务 A/B/C、离线运行。

## 2. 陶坯模型与确定性内核 `pottery.ts`

- **轮廓模型**：控制点列 `{ y, r }`（y=归一化高度 0–1.2，r=归一化半径 0.05–1），旋转体天然轴对称；
- **塑形操作**：`stretchProfile`（拉长/压缩，底不动）、`scaleRadius`（胖瘦）、`pinchProfile`（高斯衰减的局部捏塑——"手在哪捏哪"）、`smoothProfile`（半径移动平均抑制手抖毛刺）；
- **度量与分类**：`potMetrics`（高度/最大半径及相对位置/体积 Σπr̄²dy/长宽比 aspect=height÷2maxR）、`classifyShape`（碗=宽扁且最宽处偏下、瓶=aspect≥1.4、自由造型）；
- **彩绘数学**：`strokeSegments`（笔迹插值防断线）、`symmetricStamps`（n 重旋转对称副本）、`coverageRatio`（素坯底色偏离像素统计）；
- 12 项单测（含顶部切割）：默认坯合法性、三操作钳位数学、Catmull-Rom 插值单调性、圆柱体积与 πr²h 对照、三分类、对称复制、笔迹插值、覆盖率端点。

## 3. 三维视图 `PotteryView.tsx`（CubeView 生命周期模式）

- 陶轮（转盘+底座）持续旋转，陶坯 = LatheGeometry（Catmull-Rom 平滑轮廓 × 64 段），MeshPhongMaterial 贴 **CanvasTexture（1024×512）**；
- **几何重建节流 50ms**（仅 profile 真变时）；rAF 只做旋转+渲染；tick 内不引用 world.current（白屏教训）；卸载按完整清单 dispose；
- **彩绘模式转轮自动减速至 20%**（模拟真实"慢轮上釉"），拉坯模式常速，挥手可加速。

## 4. 交互（双层拉坯 + 3D 直接彩绘）

**拉坯（双层手势）**：
- 单手捏合=捏泥：捏合瞬间屏幕高度映射陶坯高度，作用高度跟随手移动，横向位移=该处收/放半径（增量 pinchProfile + 平滑）；
- 双手捏合=整体变形：从**锚点快照**（而非增量累积）出发——同向上下=拉长/压缩、张合=胖瘦（避免漂移，与几何实验的 drag 快照模式一致）；
- 分界自然：双手都入镜并捏合=整体，单手捏合=捏泥；
- 鼠标完整备用：侧栏**轮廓编辑器**（侧影+可拖控制点，拖完按 y 排序）。

**彩绘**：模式切换后捏合=落笔、移动=笔迹——raycast 命中陶坯 → UV → 在 CanvasTexture 盖章（`strokeSegments` 按笔刷间距插值）；对称档位（2/4/8 重）把每次笔画复制为环形纹样（`symmetricStamps`）；十种传统釉色（青花/釉里红/豆青/赭石/天青/钴蓝/姜黄/黑釉/珊瑚/白釉）+ 三档笔刷 + 清除彩绘。

## 5. 任务设计

| 任务 | 类型 | 判题 |
|---|---|---|
| A · 拉坯规律预测 | 迷思概念三选一 | 正确=「变高变薄」（泥量守恒，拉高必变薄——真实拉坯规律）；提交后现场验证 |
| B · 造型挑战 | 构造（目标循环） | 「高瘦的瓶」aspect≥1.4 /「宽扁的碗」aspect≤0.85 且 maxRy≤0.45——metrics 确定性判题 |
| C · 对称纹样彩绘 | 创作 + 量化判定 | 覆盖率≥6%（coverageRatio 像素统计）+ 釉色≥2 种 + ≥2 重对称 |
| 工具 · 顶部切割 | 割泥线 | `clipProfile`：保留切割高度以下轮廓、切口压平（参考同类手势陶艺产品的"切割"能力） |
| 工具 · 导出 | 作品照 PNG / 3D 模型 GLB（含彩绘贴图） | preserveDrawingBuffer 截帧 + GLTFExporter 二进制导出 |

## 6. 测试与边界

- 内核 11 项 + 场景 4 项（接入/A 判题/B、C 门控）；全量 219 项通过；
- 边界：轮廓只有旋转对称（无手捏不对称细节——教学聚焦对称美感）；体积为梯形近似；快照导出轮廓+度量+釉色/对称选择+覆盖率与 128×64 缩略思路（当前版本导轮廓与数值，纹理缩略图留作迭代）；陶轮转动方向固定；不做烧制变形模拟。
