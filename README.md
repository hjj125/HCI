# EmbodiedEdu 基础版

向智慧教学的多模态交互工作台：课件、隔空白板、空间几何探究三个视图共用一个交互内核，手势与鼠标产生相同的语义事件。

## 启动

```powershell
npm install
npm run dev
```

打开终端显示的本机地址（通常为 `http://127.0.0.1:5173/`）。PowerPoint 桌面控制只在 Windows 的 `npm run dev`/`npm run preview` 本机服务器中启用；静态托管不包含桌面桥接。

首次启用摄像头手势时，模型从本机 `public/mediapipe/` 加载，不联网。若该目录缺少模型文件，运行：

```powershell
node scripts/setup-model.mjs
```

## 三个视图

| 视图 | 键盘 / 鼠标 | 手势 |
|---|---|---|
| 课件 | ← → 翻页；可导入图片课件，或控制本机 PowerPoint | 手掌左右挥动翻页；比“2”保持 0.6 秒开关激光笔（手指方向显示红色光点，光点仅显示在本工作台内）；指向按钮捏合仍可点击一次 |
| 白板 | 按住鼠标绘制；Esc 取消；Ctrl+Z 撤销 | 捏合落笔、移动绘制、松开抬笔（可切换为空格落笔）；比“2”保持 0.6 秒切换画笔、比“3”切换橡皮；指向按钮捏合也可切换 |
| 空间几何 | 拖动滑块或捏合三维视图改切面参数；按钮/键盘操作任务 | 捏合三维视图或滑块区域拖动调整当前模式参数 |
| 力与运动 | 拖动力矢量（大小=距离，方向=指向）；空格开始/暂停 | 捏合红色力矢量头部拖动；语音“开始/暂停/重置” |

白板工具：颜色、粗细、画笔/橡皮切换（比“2”保持约 0.6 秒切画笔、比“3”切橡皮——单指是指向姿势故不用“1”；也可指向按钮捏合或鼠标点击；选中橡皮时手势指针变为方形）、落笔方式（捏合或空格）、握拳 0.6 秒撤销、撤销、清空确认。切到其他视图会先结束当前操作，已完成的笔迹与课件页码保留。

空间几何：默认进入演示模式（全部解锁，适合教师课堂演示），另设任务 A 预测验证、任务 B 寻找形状、任务 C 快照对比（保存两个切面快照，并排比较边数变化与参与面的增减）。切面经过的立方体面在三维视图中以琥珀色高亮，侧栏实时列出参与面并标记新加入的面。操作模式分为切面位置、方位角、仰角三种，避免用单目摄像头猜测三维手掌姿态；手势可捏合三维视图或滑块区域拖动调整。四个预设分别对应三、四、五、六边形（有单元测试保证）。提示分 4 级，需主动点击；停留超过 60 秒会出现一次非强制的提示入口。截面边数与二维轮廓由同一几何算法给出，边数、退化与“与面重合”等特殊状态都有显式标记。

力与运动：默认演示模式（拖动红色力矢量改变大小与方向，绿色箭头为速度，确定性牛顿仿真）；任务 A 验证“不施力时保持匀速直行”（牛顿第一定律迷思概念）；任务 B 从静止出发靠施力抵达目标区；任务 C 保存两条轨迹并排对比。仿真为纯函数半隐式欧拉积分，物理正确性由单元测试锁定。语音“开始/暂停/重置”可用。

交互过程记录默认只存元数据（不含画面），可在页面底部导出 JSON，包含任务、预测、提示次数、耗时与事件列表。

## 平台架构：可插拔场景

壳（`src/App.tsx`）只负责导航、感知（摄像头/语音）、输入路由与学习记录；学科功能全部是 `src/scenes/` 下的场景插件：

```text
src/core/      交互内核：统一事件总线、手势/语音语义、场景服务契约
src/scenes/    场景插件：slides/ 课件 · whiteboard/ 白板 · geometry/ 空间几何 · physics/ 力与运动
src/scenes/registry.ts   场景注册表——新增学科 = 新建目录 + 登记一行
```

场景通过 `core/services.tsx` 提供的契约与平台交互（通知、手势策略注册、会话快照、拖拽会话），场景之间互不可见；鼠标、手势、键盘、语音产生相同的语义事件，由各场景自行解释。所有场景保持挂载、仅激活场景可见，切换时自动结束旧操作并保留各场景状态。

## 控制本机 PowerPoint

1. 使用 Windows 桌面版 PowerPoint 打开 `.pptx` 文件。
2. 在 PowerPoint 按 **F5** 开始放映；使用窗口放映时可选择“设置幻灯片放映 → 观众自行浏览（窗口）”。
3. 回到 EmbodiedEdu → 课件 → **本机 PowerPoint** → 检测连接。
4. 打开摄像头。张开手掌**向右挥 = 下一页**，**向左挥 = 上一页**，不必瞄准屏幕上的按钮；一次挥手只翻一页。
5. 也可以点击按钮或使用键盘方向键。按钮、挥手与键盘共用同一翻页命令。

PowerPoint 按其原生放映行为处理命令：有动画时，“下一页”可能先推进动画；上一页也可能先回退动画。

### 激光笔

课件视图中比“2”保持约 0.6 秒开关激光笔（或按 L 键、点击“激光笔”按钮）。开启后手指指向显示为红色光点，替代普通手势光标；挥手翻页不受影响，两者使用独立手势。光点绘制在本工作台页面内——控制外部 PowerPoint 时它不会出现在 PowerPoint 窗口上；需要在投影大屏上指示时，请用“应用内课件”模式放映本页面。

### 语音命令

点击导航栏“语音命令”启用（Edge / Chrome，需麦克风权限）。识别到短语后转为统一交互事件执行，与手势、鼠标共用同一事件总线：**下一页 / 上一页**（仅课件视图）、**白板 / 课件 / 几何 / 物理**（切换视图）、**撤销、重置、提示、激光笔、开始 / 暂停**（仿真）、**关闭语音**。状态栏实时显示转写与执行结果，未识别的语句只提示不执行；破坏性操作（如清空白板）不设语音入口。语音识别由浏览器语音服务完成，本应用不保存音频与转写。

### 后台摄像头与挥手判定

勾选“允许 PPT 模式下后台使用摄像头”后，切换到 PowerPoint 窗口仍继续识别，避免单屏演示时必须并排窗口。识别循环由 Web Worker 定时器驱动，不受浏览器对后台页面主线程定时器的节流影响（后台约每秒采样 10 次）。翻页方式不变，仍是挥手，因此不需要盯着屏幕也不需要用手指去够某个区域。

判定条件（`src/pptGesture.ts`，有单元测试覆盖）：横向位移至少 18% 屏幕宽、耗时 80—700ms、同向位移占比 ≥85%、上下位移不超过 18%。捏合开始时清空轨迹并在随后 0.3 秒内不判定，避免“伸手去点按钮”的移动被误认为翻页；持续捏合中不再逐帧清空，放松的手型（拇指贴近食指）也能挥手翻页。每次识别后进入 0.9 秒冷却，所以一次挥手只翻一页。离开课件视图时会清空轨迹，白板和几何里的横向拖动不会翻页。

### 单屏和双屏

未勾选后台摄像头时，浏览器隐藏到后台会停止识别以保护隐私。单屏演示建议把 PowerPoint 设置成窗口放映，与浏览器并排；全屏放映推荐双屏，一屏放映、一屏保留浏览器工作台。按 Esc 退出 PowerPoint 全屏再回到浏览器。

## 安全与隐私

- 本机接口只接受 localhost 请求，并校验同源及自定义请求头；不开放 CORS。
- PowerPoint 桥接只连接已有 PowerPoint 实例，不启动、保存、修改或关闭文稿。
- 只发送翻页/状态命令；不上传 PPT，也不保存演示画面。
- 接口对连续命令限速，防止连续挥手或抖动造成快速翻页。
- 摄像头画面只在本地推理，默认不录制、不上传。
- 语音命令显式启用；识别由浏览器语音服务完成，本应用不保存音频或转写。

如果无法连接，请确认 PowerPoint 已启动、文稿已打开并开始放映；关闭任何模态对话框。若浏览器与 PowerPoint 以不同 Windows 权限运行（例如一方“以管理员身份运行”），请改为相同权限级别后重试。

## 功能边界

已实现：三视图切换与状态保留、课件翻页与图片导入、本机 PowerPoint 桥接、**左右挥手翻页**、**比“2”开关激光笔（L 键/按钮备用）**、白板绘制/橡皮/撤销/清空、**比“2”“3”数字手势切换画笔/橡皮**、手势指针与捏合抓取（含释放确认、追踪丢失回滚）、正方体截面计算与三维/二维联动、**切面经过面高亮**、**演示模式与任务 A/B/C（快照对比）**、**物理·力与运动场景（力矢量拖动 + 牛顿仿真 + 任务 A/B/C）**、分级提示、事件记录与导出、**有限语音命令（翻页/切视图/撤销/重置/提示/激光笔）**、鼠标与键盘完整备用路径。

尚未实现（不在当前版本宣称范围内）：第二学科场景、数据库持久化（记录仅存于内存，刷新即失）、课件编辑、手写 OCR。单目摄像头只用于二维控制信号，不恢复真实手掌六自由度。
