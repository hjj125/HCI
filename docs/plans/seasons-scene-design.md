# 地理实验三 · 五带与四季（geo-seasons）设计方案

状态：已实现。本文档记录设计决策，供课程报告与后续迭代引用。

## 1. 定位与教学目标

地理学科的第三个实验，与前两个实验（找国家、晨昏线）共享 `GlobeView` 三维地球与 `solarMath` 天文内核，构成完整的教学因果链：

**直射点周年运动（五带与四季）→ 太阳高度角（随纬度与时刻）→ 昼夜长短与影长（可观察现象）**

教学目标（初中地理）：
- 五带划分：热带（±23.44° 之间）、南北温带、南北寒带，分界即回归线与极圈；
- 四季成因：太阳直射点随公转在回归线间往返，正午太阳高度与昼长随之变化；
- 极昼极夜：极圈内纬度在特定季节出现；
- 正午太阳高度与影长：影长最短 = 太阳高度角最高 = 当地太阳时 12:00（"立竿见影"）。

**术语约定**：实验内使用"太阳视运动 / 周年运动"。教材中"太阳活动"专指黑子、耀斑等，与本实验无关，避免概念混淆。

## 2. 复用与新增

复用（零新数据源、全离线）：
- `GlobeView`：三维地球、手势拾取、飞行定位、惯性旋转；
- `solarMath.subsolarPoint`：赤纬周年正弦近似（回归年 365 天）+ UTC 时角；
- 地理组既有模式：演示 + 任务 A/B/C、确定性判题、2 级提示、60 秒停滞提醒、反思提交、会话快照导出、同一套手势词汇。

新增（`src/scenes/geography/solarMath.ts` 纯函数，全部有单测）：
| 函数 | 说明 |
|---|---|
| `zoneOf(lat)` | 五带划分（分界值归高纬侧） |
| `daylightHours(lat, decl)` | 昼长：cos H₀ = −tanφ·tanδ，极昼 24h / 极夜 0h 边界显式处理 |
| `daylightState(hours)` | 极昼/昼长夜短/昼夜平分（±3 分钟）/昼短夜长/极夜 |
| `altitudeAtSolarHour(lat, decl, solarHour)` | 太阳高度角 sin h = sinφ·sinδ + cosφ·cosδ·cosH |
| `solarAltitude(lat, lon, utc, doy)` | 由日期取赤纬、UTC+经度取时角；>0 ⟺ isDaylight（一致性有测试锁定） |
| `shadowRatio(lat, lon, utc, doy)` | 影长/杆高 = 1/tan(h)，h≤0 返回 null；直射趋于 0（"立竿无影"） |
| `sunriseSunset(lat, decl)` | 日出日落当地太阳时，极昼 [0,24]、极夜 null |

`GlobeView` 扩展（默认关闭，不影响找国家/晨昏线）：
- `zones`：五带着色 overlay 球壳（ShaderMaterial 按 vUv.y 分带）+ 四条分界纬线；
- `subsolarMarker`：太阳直射点黄色标记（经度随 UTC 移动）；
- `highlightZone`：语音点名高亮某带（uniform 切换透明度）。

## 3. 交互设计

- **手势：零新增词汇**。与找国家/晨昏线完全同套 policy（捏合点击选中、捏合拖动旋转、挥手惯性自转、双手张合缩放），符合"最小动作集合"设计原则。
- **语音**：全局新增"四季"切换短语；场景级策略（`useSceneVoicePolicy`）解释节气名（跳日期）、五带名（高亮）、"正午"（任务 C 直达当地正午）。播报后沿用 `pauseRecognition` 防自激；同短语 10 秒去重。
- **全局—局部视角联动**（任务 C）：主视图为全局地球，侧栏为面向赤道的剖面影子视图（2D Canvas：当日轨迹弧线 + 当前太阳位置 + 标杆与影长）；在地球上点选城市，剖面视图即切到该纬度。这是本实验的 HCI 设计点：多视图联动帮助建立"球面—当地天空"的空间认知。
- **日期与时刻双滑杆**：日期滑杆（1–365 天 + 节气按钮）驱动轨迹弧线形状；"一天时刻"UTC 滑杆驱动太阳在弧线上的位置——与晨昏线实验的 UTC 滑杆心智一致。

## 4. 任务设计（确定性判题）

| 任务 | 类型 | 判题 |
|---|---|---|
| A · 五带昼夜预测 | 预测验证（5 题题库：北京/新加坡/悉尼/摩尔曼斯克/圣保罗 × 节气） | `zoneOf` + `daylightState(daylightHours)`；提交后地球飞至该城该日亲眼验证 |
| B · 追寻极昼 | 构造（摩尔曼斯克/朗伊尔城·极昼，中山站·极夜） | 昼长状态匹配；**春分开局**（赤纬≈0，开局必不达成，防止任务未做先完成） |
| C · 影长实验 | 探究 + 轻判题 | 当地太阳时距正午 ≤15 分钟且太阳已升 → 自动判定"正午达成"；达成后对比不同节气弧线并提交反思 |

彩蛋教学点：广州（北回归线内）夏至正午"立竿无影"（影长比 ≈ 0.005）；极昼时太阳整日不落、影子整天存在。

## 5. 测试计划（已实现）

- `solarMath.test.ts`：五带边界值、赤道/回归线/极圈/极点昼长（夏至赤道 12h、北极圈 24h）、正午太阳高度 = 90°−|φ−δ|、影长（立竿无影 <0.01、夜间 null）、`solarAltitude` 与 `isDaylight` 一致性抽样、日出日落。
- `seasons.test.tsx`（jsdom + App 级）：场景接入（页签/滑杆/开关）、任务 A 两维预测判题（对/错/换题）、任务 B 春分开局未达成→夏至达成→解释解锁提交、任务 C 剖面视图渲染与正午自动判定。
- 全量 `npm test` 122 项通过；`npm run build` 通过。

## 6. 边界

- 不引入任何新数据源：日期为回归年近似（节气取固定 doy：80/172/266/355），不做完整天文历表；不做日晷盘方位角俯视图（可由任务 C 升级为独立实验四）。
- 影子剖面视图为示意性二维投影（面向赤道约定：左东右西），高度角数值本身是确定性的。
- 手势词汇与 AI 能力不变：本实验不调用 LLM，全部判定离线确定性计算。
