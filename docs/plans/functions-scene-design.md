# 数学实验二 · 人体函数绘图仪（functions）设计方案

状态：已实现（阶段一拟合内核原型验证 + 阶段二完整实验）。本文档记录设计决策，供课程报告引用。

## 1. 定位与教学目标

兑现《总体设计方案》3.3 创新场景池中的「人体函数绘图仪」：**让学生用身体"画出"一条函数曲线，系统识别类型并给出表达式**。教学价值是把函数的三种表示打通——身体动作（指尖高度）→ 图像（曲线）→ 符号（表达式），直击"图像是一幅画而不是一个关系"的常见迷思；对应数学教育中经典的 motion graph / "走函数"活动传统。

**与形状识别的本质区别**：不做墨迹图像识别。手就是画笔，轨迹本身已是函数采样——"识别"是纯数值最小二乘拟合，确定性、可单测、离线。

## 2. 阶段一：拟合内核原型验证（先于 UI）

`src/scenes/functions/functionFit.ts` 纯函数内核：
- 预处理：滑动平均去抖 → 按 x 均匀重采样（抗扫速不匀与丢帧，跨度 <0.1 拒绝）；
- 三族拟合：直线闭式最小二乘；二次 3×3 正规方程（克拉默法则）；正弦 = 周期对数网格搜索（0.25–4 共 96 档）+ 每档对 (mid, A, B) 的线性最小二乘 + 抛物线细化（网格 3% → 约 0.1%）；
- 分类：三族残差比较 + **族合理性门限**（|a|/amp < 0.08 的"假曲线"退回直线）+ **简约性惩罚**（复杂族须以 <70% 残差胜出）+ 双门限拒识（残差 >0.1 或拟合跨度 <0.1 → null，"没认出来请重画"）。

**仿真验收**（`functionFit.test.ts`，种子化 LCG + Box-Muller，可精确复现）：高斯噪声三档（σ=0.01/0.03/0.05）× 20% 丢帧 × 非均匀扫速，三族各 70 轨迹**全部 100% 正确分类**（验收线 90%）；参数恢复 k/a ±10%、周期 ±15%；拒识路径（手没动/纯噪声/乱画涂鸦）有测试锁定。

**关键发现**：手挥出画布边缘的截断平顶会让长周期正弦有机可乘——精度口径限定为画布内绘制，UI 负责引导；此为真实采集伪影，已记录在提交信息与测试注释中。

## 3. 阶段二：完整实验

### 交互管线（鼠标/手势同一路径）
```
捏合落笔 / 鼠标按下 → drag start（画布归一化坐标 [0,1]²，手势经视口→画布矩形换算）
捏合移动 / 鼠标拖动 → drag update（>0.006 间距才采样，~40 点/秒）
松开抬笔           → drag end → toMath（x∈[-1,1] 向右、y∈[-1,1] 向上）→ classify → 表达式 + 拟合曲线叠画
```
手势坐标换算复用白板模式（视口归一化 × 窗口尺寸 → 画布矩形 ±边距 → 相对坐标），经由统一事件总线的 drag 语义事件，鼠标与手势无差别。

### 画布可视化（2D Canvas，1200×560）
网格 + 坐标轴 + 青色笔迹 + 琥珀色拟合曲线 + 灰蓝虚线目标曲线（任务 A 常显；任务 B 提示 2 级后显示参考虚线）。

### 任务设计（确定性判题，`taskLogic.ts`）
| 任务 | 类型 | 判题 |
|---|---|---|
| A · 看曲线猜类型 | 预测验证（5 题：直线/抛物线/正弦各态） | 预测族别 = 目标族别；提交后揭晓表达式 |
| B · 听指令画函数 | 构造（上升/下降直线、开口向上/向下抛物线、完整的波） | 族别 + 参数约束（k 正负、a 开口、周期 ≤2.2）；提示 2 级显示参考虚线 |
| C · 双曲线对比 | 快照对比 | 两笔自动存为对比①②，表达式并排展示 + 开放反思 |

侧栏"拟合识别"面板除表达式外解释参数的物理含义（斜率=每画布宽的高度变化、开口方向、振幅/周期/中线）。

### 语音
全局新增"函数"切换短语；场景级策略："直线/抛物线/正弦/波浪"口头预测（任务 A 中直接选中族别 chips）、"清除/重画"清空笔迹；播报后沿用 pauseRecognition 防自激。

## 4. 测试

- `functionFit.test.ts`：内核单元 + 仿真精度验收（阶段一）；
- `taskLogic.test.ts`：目标函数画布内约束、B 判题矩阵（族别×参数）、表达式格式化（符号/零项省略）；
- `functions.test.tsx`（App 级 jsdom）：场景接入、演示模式识别结果、任务 A 预测流程、任务 B 达成/未达成、任务 C 双笔对比与提交门控。**测试技巧**：笔迹经事件总线直接注入（鼠标与手势同一条 drag 路径），用 React 的 `act()` 包裹以刷出状态更新。
- 全量 `npm test` 146 项通过。

## 5. 边界

- 拟合域固定为画布归一化 [-1,1]，不做坐标标定/单位换算；周期/振幅均以"画布宽/高"为单位表述；
- 不支持圆等非单值曲线（自由画线模式未纳入本期——横扫模式天然保证单值性，自由画线留作后续探索）；
- 不引入 ML/形状识别；不训练模型；全部离线确定性计算；
- 出界截断的鲁棒性（自动裁剪平顶段）留作后续迭代，当前以 UI 引导规避。
