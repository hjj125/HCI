## 1. 天文·月相仪（地理组第四实验）

**教学目标**：月相成因（日-地-月相对位置）、月相名称与周期（朔望月 ≈29.53 天）、照亮比例与可见规律。与"五带与四季"构成天文双实验。

**内核 `moonMath.ts`**：
- `phaseFromElongation(elongDeg)` → `{ name, illumination }`：照亮比例 = (1 − cos elong)/2；名称按距角分段（0° 新月、90° 上弦、180° 满月、270° 下弦，中间为蛾眉/盈凸/亏凸/残月）；
- `moonAgeToElongation(ageDays)`：均匀朔望月线性映射；
- `moonPhaseOnDate(date)`：以已知朔日锚点（2000-01-06 18:14 UTC）推算月龄——**教学近似**（均匀朔望月，误差 ≤1 天级，文档/界面明示）；单测锚点：锚点日=新月、+14.77 天=满月；
- `visibleHours(elong)`：可见时段教学模型（满月整夜、上弦半夜落、残月黎明见）；
- `phaseShape(elongDeg)`：地面视角亮面形状参数（亮侧方向 + 明暗界线椭圆半宽因子 |cos|）——月相的本义是"从地球看到的形状"，必须有此视图。

**可视化（新建 `MoonView.tsx`，Three.js 简场景）**：地球小球居中、月球小球绕转，方向光模拟太阳（月球的昼夜半球自然呈现）；太阳方向箭头。控件：月龄滑杆（0–29.5）、"今天"按钮、四相快捷键、播放键。手势零新增：捏合拖动=直接调月龄、左右挥手=月龄冲量（带惯性）、双手张合缩放视角。

**任务**：A · 月相预测（"农历十五"→8 选 1 chips，提交后场景转到该相位验证 + 揭晓照亮比例）；B · 追寻上弦月（距角 90°±5°，与"追寻极昼"同构）；C · 朔望对比（分别调到新月/满月并保存两个快照，对比照亮比例，反思"为什么十五的月亮圆"）。

**语音**：场景级"新月/上弦/满月/下弦"跳相位、"今天"查当日月相（TTS + 防自激）。

**边界**：不做真实星历与农历历法表、不做日月食、不做轨道倾角（白道 5° 忽略）。

## 2. 数学·身体量角器（数学组第三实验）——全项目最"具身"

**教学目标**：角度概念与度量、特殊角（60/90/120/180）、三角形内角和 180°；引入"测量有误差"的实验观。

**唯一的平台层改动**：`HandSample` 增可选字段 `landmarks?: { x: number; y: number }[][]`（双手各 21 关键点，镜像归一化；`useHandInput` 已有数据只是没传出来）。向后兼容，不影响现有场景。

**内核 `bodyAngle.ts`**：
- `angleAt(a, b, c)`：b 为顶点的三点夹角（向量点积），度数 [0,180]；
- **双手角**：两手各伸食指 → `angleAt(左食指尖, 两腕连线中点, 右食指尖)`，0–180°；
- **虎口角**（单手小角测量仪，0–90°）：`angleAt(拇指尖, 拇指掌根, 食指尖)`；
- `classifyAngle(deg)`：锐角/直角/钝角/平角；`isWithin(deg, target, tol)` 判题；
- `stabilize(samples, tol)`：滑动窗口极差 < tol → 锁定（取中位数，抗手抖）；
- 单测：正交 90°/共线 180°/等边 60° 精确值、镜像一致性、稳定窗口判定。

**可视化（2D Canvas）**：摄像头预览 + 手部骨架叠加 + 顶点角度弧线 + 大号度数；副视图为标准量角器刻度盘（指针指当前角、目标角扇形高亮）。

**交互**：手势零新增——实时显示无需操作；**捏合一下 = 锁定/解锁读数**（复用捏合点击语义）；语音"锁定/解锁""读数"（TTS 播报 + 防自激）；鼠标全功能按钮。测量本身必须摄像头（同"背诵必须语音"口径）。

**任务**：A · 角度预测（随机目标角扇形 → 预测锐/直/钝角 → 揭晓度数）；B · 拼指定角（60°/90°/120°，±8° 判定）；C · 内角和探究（依次摆三个角各自锁定 → 求和 vs 180°，**±12° 宽容差达成**——"为什么有误差"本身是教学点）。

**边界**：MediaPipe Hands 只有手部关键点——不做躯干/腿、不做多人同测；双手需同时入镜（状态栏引导）。

## 3. 化学·分子搭建（化学组首个实验）

**教学目标**：分子由原子构成、化学式书写、价键规则（H=1 O=2 N=3 C=4）、同分异构体初步。

**内核 `molecule.ts`**：
- `VALENCE = { H:1, O:2, N:3, C:4 }`（教学简化，不含离子键/金属键）；
- `validateMolecule(atoms, bonds)` → `{ ok, errors[] }`：键数超价、**连通性**（多个孤立部分 → "这不是一个分子"）；
- `molecularFormula(atoms)`：**希尔式**规范书写（C 优先、H 其次、其余字母序）；
- `isomerDifferent(a, b)`：同化学式下结构不同——教学级图不变量（度序列 + 邻域多重集），能区分正/异丁烷；标注为充分条件而非完全同构判定；
- 支持双键（CO₂ 需要 C=O）。

**可视化与交互（`MoleculeView.tsx`，Three.js 球棍模型）**：CPK 配色球（H 白、C 深灰、O 红、N 蓝）+ 圆柱键（双键双圆柱）；**点选式成键**（与"找国家"指向+捏合一致，规避三维抓取精度）：指向原子捏合=选中，选中两个→成键，已键合再点→升级双键→再点→断键；捏住原子拖动=移动；元素托盘捏合=添加原子；轻量弹簧布局让分子舒展（仅视觉，不影响判题）；拖回托盘/语音"删除选中"移除。鼠标同路径。

**任务**：A · 价键预测（"氧原子最多连几个氢？"chips，提交后现场试搭验证）；B · 搭出目标分子（H₂O → O₂（双键）→ CO₂ → NH₃ → CH₄ 递进，validate+formula 判题）；C · 同分异构体（4C+10H 搭两种不同结构）。

**语音**："添加氢/碳/氧/氮""删除选中""清除重来"。

**边界**：不做键角约束与能量优化、不做全元素周期表、不做立体化学（手性）。

## 4. 语文·古诗词背诵镜（语文组首个实验）

**教学目标**：古诗词记诵与易错字强化；给教师课堂听写工具。**定位为形成性工具**——ASR 的同音转写无法区分"读错"与"听错"，这一局限诚实写进界面与文档（符合项目"不据此宣称"的一贯立场）。

**内核 `recite.ts`**：
- `normalize(text)`：去标点/空白（篇目内置固定版本，备注教材差异）；
- `alignTexts(expected, heard)`：**编辑距离 DP（Wagner-Fischer）+ 回溯** → 逐字对齐序列，四态：正确 / 不匹配（提示原文，含同音可能）/ 漏字 / 多字；
- `score(alignment)`：完整度 = 正确数/原文长度 + 错字清单（位置+原字+听到的字）；
- 篇目库 `poems.ts`：内置 8–12 首公开领域课标古诗（静夜思、春晓、登鹳雀楼、望庐山瀑布、赋得古原草送别、悯农、咏鹅、绝句…），预切句供听写模式；
- 单测：完全一致/漏字/错字/添字/乱序/空输入/重复字句边界。

**交互**：篇目列表 → 背诵界面（原文隐藏，"你的背诵"实时显示 ASR 转写）→ 对齐视图（原文逐字色块：绿=对、黄=不匹配、灰=漏、红=多）+ 完整度大数字。**语音是本实验的灵魂输入**（连续 ASR）；听写模式的"读上句→接下句"正是防自激机制（9527bfd）的主场。手势零新增（捏合点按钮）；鼠标完成全部非背诵操作（背诵动作为语音专属，同"课件翻页之于挥手"口径）。音频不保存，仅转写文本进会话快照。

**任务**：A · 听写接句（逐句 TTS 读上句 → 学生接下句 → 每句即时对齐，全对达成）；B · 全文背诵（完整度 ≥90% 达成 → 反思易错字）；C · 错字本（本会话两次背诵的错字集合对比）。
