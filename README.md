# EmbodiedEdu 基础版

向智慧教学的多模态交互工作台：课件、隔空白板与数学/物理/化学/地理/语文共十二个学科实验共用一个交互内核，手势、语音、鼠标与键盘产生相同的语义事件。

## 启动

```powershell
npm install
npm run dev
```

打开终端显示的本机地址（通常为 `http://127.0.0.1:5173/`）。PowerPoint 桌面控制只在 Windows 的 `npm run dev`/`npm run preview` 本机服务器中启用；静态托管不包含桌面桥接。

首次启用摄像头手势时，模型从本机 `public/mediapipe/` 加载，不联网。若该目录缺少模型文件，运行：

```powershell
node scripts/setup-model.mjs
```

## 场景与视图

| 视图 | 键盘 / 鼠标 | 手势 |
|---|---|---|
| 课件 | ← → 翻页；可导入图片课件，或控制本机 PowerPoint | 手掌左右挥动翻页；比“2”保持 0.6 秒开关激光笔（手指方向显示红色光点，光点仅显示在本工作台内）；指向按钮捏合仍可点击一次 |
| 白板 | 按住鼠标绘制；Esc 取消；Ctrl+Z 撤销 | 捏合落笔、移动绘制、松开抬笔（可切换为空格落笔）；比“2”保持 0.6 秒切换画笔、比“3”切换橡皮；指向按钮捏合也可切换 |
| 空间几何 | 拖动滑块或捏合三维视图改切面参数；按钮/键盘操作任务 | 捏合三维视图或滑块区域拖动调整当前模式参数 |
| 力与运动 | 拖动力矢量（大小=距离，方向=指向）；空格开始/暂停 | 捏合红色力矢量头部拖动；语音“开始/暂停/重置” |
| 数字地球 | 拖动旋转地球（水平+俯仰）；单击选区；滚轮缩放 | 左右挥动=自转、上下挥动=俯仰（带惯性）；指向国家捏合一下=选中、捏合保持≈0.7秒=直接进入详情（选点取捏合前指向位置）；捏合拖动=微调旋转；张开手掌悬停≈刹车；双手张合缩放（无需切换模式） |
| 五带与四季 | 拖动日期/一天时刻滑杆；点选城市；节气按钮 | 与数字地球同词汇：捏合选中、捏合拖动旋转、挥手惯性、双手张合缩放 |
| 函数绘图 | 按住鼠标在画布上画线（从左到右）；按钮操作任务 | 捏合落笔后从画布左缘扫到右缘：指尖高度=函数值；松开抬笔即识别 |
| 月相仪 | 拖动月龄滑杆；农历日/四相/今天按钮 | 捏合拖动=直接调月龄、左右挥手=时间快进/回退（惯性）、双手张合缩放 |
| 身体量角器 | 按钮：模式切换/锁定读数/记录（测量本身需摄像头） | 双手各伸食指拼角（或单手虎口角），实时读数；手稳定后捏合一下=锁定 |
| 分子搭建 | 按钮：添加 H/C/N/O、删除选中、清空 | 指向原子捏合一下=选中，点选两个原子=成键；已键合再点=升双键、再点=断键；按住原子拖动摆姿势 |
| 背诵镜 | 按钮：开始/结束背诵、显示原文、保存结果（背诵动作本身为语音专属） | 捏合点选按钮即可；对麦克风背诵由语音识别逐字对齐 |

白板工具：颜色、粗细、画笔/橡皮切换（比“2”保持约 0.6 秒切画笔、比“3”切橡皮——单指是指向姿势故不用“1”；也可指向按钮捏合或鼠标点击；选中橡皮时手势指针变为方形）、落笔方式（捏合或空格）、握拳 0.6 秒撤销、撤销、清空确认。切到其他视图会先结束当前操作，已完成的笔迹与课件页码保留。

空间几何：默认进入演示模式（全部解锁，适合教师课堂演示），另设任务 A 预测验证、任务 B 寻找形状、任务 C 快照对比（保存两个切面快照，并排比较边数变化与参与面的增减）。切面经过的立方体面在三维视图中以琥珀色高亮，侧栏实时列出参与面并标记新加入的面。操作模式分为切面位置、方位角、仰角三种，避免用单目摄像头猜测三维手掌姿态；手势可捏合三维视图或滑块区域拖动调整。四个预设分别对应三、四、五、六边形（有单元测试保证）。提示分 4 级，需主动点击；停留超过 60 秒会出现一次非强制的提示入口。截面边数与二维轮廓由同一几何算法给出，边数、退化与“与面重合”等特殊状态都有显式标记。

力与运动：默认演示模式（拖动红色力矢量改变大小与方向，绿色箭头为速度，确定性牛顿仿真）；挑战模式·星际巡游小游戏（从起点停机坪出发，按 ①②③ 顺序收集随机信标后进入终点传送门，计时结算用时/施力/出界次数，出界送回起点但计时不停；“换一张星图”重新随机课程点）；任务 A 验证“不施力时保持匀速直行”（牛顿第一定律迷思概念）；任务 B 从静止出发靠施力抵达目标区；任务 C 保存两条轨迹并排对比。仿真为纯函数半隐式欧拉积分，物理正确性由单元测试锁定；初速 1.5 m/s、力上限 4 N，物体到达观测区边缘自动暂停。语音“开始/暂停/重置”可用。

化学实验一 · 分子搭建：Three.js 球棍模型（CPK 配色：H 白/C 深灰/N 蓝/O 红），从托盘添加原子、**点选两个原子成键**（同一对再点升双键、再点断开），按住原子拖动摆姿势（内置弹簧布局，仅视觉不影响判题）。判题内核：价键规则（H=1 C=4 N=3 O=2）、连通性（多孤立部分提示“混合物”）、分子式按教科书惯例书写（碳优先、无碳时氮优先）、同分异构体用逐原子结构签名多重集判别（能区分正/异丁烷、乙醇/二甲醚）。任务 A 价键预测（“氧最多连几个氢”）、任务 B 搭出目标分子（H₂O→O₂→CO₂→NH₃→CH₄ 递进，合法+化学式判题）、任务 C 同分异构体（4C+10H 两种结构）。语音“添加氧”“删除”“清除”。

语文实验一 · 古诗词背诵镜：对麦克风背诵课标古诗（内置 8 首公开领域篇目），**编辑距离 + 回溯的字符级对齐**把转写与原文逐字对照：绿=正确、黄=不符（可能同音）、灰色虚线=漏字、红=多字，附完整度与易错字清单。**定位为形成性工具**——ASR 的同音转写无法区分“读错”与“听错”，界面明示需人工复核。任务 A 听写接句（TTS 读上句、学生接下句，逐句即时反馈，防自激机制在此主场）、任务 B 全文背诵（完整度 ≥90% 达成）、任务 C 错字对比（两次背诵的问题字集合对比：新出现/已改正）。音频不保存，仅转写进学习记录。

地理学科包含四个实验，共享同一个三维地球组件（GlobeView）——月相仪为独立简场景（MoonView）。

实验一 · 找国家（世界地理）：离线三维地球（NASA Blue Marble 贴图 + 云层 + 大气辉光 + 星空），捏合拖动旋转、选择模式点选国家（Natural Earth 离线边界 + 点在多边形确定性判定，国家级精度，实测误差 <0.5°）；任务 A 线索定位（内置 12 条线索）、任务 B 区位分析。语音说“定位日本”等国名可飞行定位到该国（纯规则匹配 177 个中文国名，浏览器 TTS 播报确认）。

实验二 · 晨昏线：昼夜半球由确定性天文计算驱动（太阳直射点 = 赤纬周年正弦 + UTC 时角），夜半球显示城市灯光；UTC 时间滑杆（0–24h）与春分/夏至/秋分/冬至节气切换，播放键看晨昏线扫过地球；点选国家显示当地太阳时与昼夜状态。任务 A 昼夜预测（给定 UTC 预测目标城市昼/夜，isDaylight 确定性判题，提交后地球自动调到该时刻验证）、任务 B 追寻白昼（调整时间使指定国家全境白昼/黑夜，多边形采样点实时判定）。区域详情为双视图：**资料卡**（离线内置的区位/地形/人文）与 **AI 问答**——点击“AI 生成讲解”切换到对话界面，DeepSeek 以流式（打字机）输出完整介绍，学生可在下方输入框**连续追问**（多轮对话，保留最近 10 轮，回复保持教学口吻并附带探究引导）；离线或未配置时在对话内提示并一键回到资料卡。

实验三 · 五带与四季：球面叠加五带着色带与回归线/极圈分界纬线，黄色标记实时显示太阳直射点；日期滑杆（1–365 天）与节气按钮驱动直射点在回归线间往返，“播放一年”看周年运动。任务 A 五带昼夜预测（预测城市所属五带与昼夜长短状态，zoneOf + daylightHours 确定性判题，提交后地球飞至该城该日验证）、任务 B 追寻极昼（调整日期使摩尔曼斯克/朗伊尔城/中山站出现极昼或极夜，春分开局）、任务 C 影长实验（**剖面影子视图**：当日太阳轨迹弧线 + 当前太阳位置 + 标杆影长实时变化，在地球上点选城市即全局—局部视角联动；把太阳调到当地正午即影长最短，自动判定达成，夏至广州正午可见“立竿无影”）。语音可说“夏至”“北温带”“正午”。

实验四 · 月相仪：太空视角（地球居中、月球绕转、方向光呈现月球昼夜半球）与**地面视角月相盘**并列——月相的本义是“从地球看到的形状”。月龄滑杆（0–29.5 天）+ 农历日对照 + 四相快捷键 + “今天”按钮（均匀朔望月教学近似，误差 ≤1 天，界面明示）；照亮比例 = (1−cos 距角)/2，可见时长与口诀（满月整夜、上弦前半夜）同步显示。任务 A 月相预测（“农历十五”→8 相 chips，lunarDayToAge + phaseFromElongation 确定性判题，提交后月球转到该日验证）、任务 B 追寻上弦月（距角 90°±5°）、任务 C 朔望对比（保存新月/满月两帧快照，对比照亮比例与可见时段）。语音可说“满月”“下弦”“今天”。

数学实验二 · 人体函数绘图仪：**用身体画函数**——捏合落笔后从画布左侧扫到右侧，指尖高度即函数值 y、横向位置即自变量 x；松开抬笔，拟合内核对采样点做最小二乘识别（直线/抛物线/正弦三族闭式求解 + 简约性比较 + 拒识门限），给出表达式并叠画拟合曲线（仿真验收：σ=0.03 噪声 + 20% 丢帧 + 非均匀扫速下三族分类 100%，见 `src/scenes/functions/functionFit.test.ts`）。任务 A 看虚线曲线猜族别（提交后揭晓表达式）、任务 B 听指令画函数（"上升的直线""开口向上的碗""一个完整的波"等，按斜率/开口方向/周期确定性判题，提示 2 级后显示参考虚线）、任务 C 双曲线对比（两笔自动存为对比①②并排比较表达式）。语音说"直线/抛物线/正弦"可口头预测，"清除/重画"清空笔迹。精度口径限定为画布内绘制——手挥出画布边缘的截断平顶是已知混淆源，界面会引导。

数学实验三 · 身体量角器：**身体即量具**——双手各伸一根食指拼成一个角（或单手虎口角量锐角），手部关键点夹角实时测量并显示度数（平台层为 HandSample 增加了 landmarks 关键点透传）。主视图为手部骨架叠加 + 顶点角度弧线，副视图为标准量角器刻度盘（指针 + 目标角扇形）。手稳定后**捏合一下=锁定读数**（取最近读数中位数，抗手抖）。任务 A 角度预测（目标角扇形 → 预测锐/直/钝/平角）、任务 B 拼指定角（60°/90°/120°，±8° 判定）、任务 C 内角和探究（依次摆三个角求和 vs 180°，±12° 宽容差——"为什么有误差"本身是教学点）。语音"锁定/解锁/读数"。

交互过程记录默认只存元数据（不含画面），可在页面底部导出 JSON，包含任务、预测、提示次数、耗时与事件列表。

## 平台架构：可插拔场景

壳（`src/App.tsx`）只负责导航、感知（摄像头/语音）、输入路由与学习记录；学科功能全部是 `src/scenes/` 下的场景插件：

```text
src/core/      交互内核：统一事件总线、手势/语音语义、场景服务契约
src/scenes/    学科实验插件（按学科分组）：课堂工具（slides/whiteboard）· 数学（geometry + functions + bodyangle）· 物理（physics）· 化学（molecule）· 语文（recite）· 地理（geography：找国家 + 晨昏线 + 五带与四季 + 月相仪）
src/scenes/registry.ts   场景注册表——新增学科 = 新建目录 + 登记一行
```

场景通过 `core/services.tsx` 提供的契约与平台交互（通知、手势策略注册、会话快照、拖拽会话），场景之间互不可见；鼠标、手势、键盘、语音产生相同的语义事件，由各场景自行解释。所有场景保持挂载、仅激活场景可见，切换时自动结束旧操作并保留各场景状态。

## 控制本机 PowerPoint

1. 使用 Windows 桌面版 PowerPoint 打开 `.pptx` 文件。
2. 在 PowerPoint 按 **F5** 开始放映；使用窗口放映时可选择“设置幻灯片放映 → 观众自行浏览（窗口）”。
3. 回到 EmbodiedEdu → 课件 → **本机 PowerPoint** → 检测连接。
4. 打开摄像头。张开手掌**向右挥 = 下一页**，**向左挥 = 上一页**，不必瞄准屏幕上的按钮；一次挥手只翻一页。
5. 也可以点击按钮或使用键盘方向键。按钮、挥手与键盘共用同一翻页命令。

PowerPoint 按其原生放映行为处理命令：有动画时，“下一页”可能先推进动画；上一页也可能先回退动画。

### AI 讲解服务端配置（数字地球）

DeepSeek key 保存在**服务端**，对课堂用户完全透明（前端无任何配置界面）：

```powershell
copy .env.example .env   # 然后编辑 .env，填入 DEEPSEEK_API_KEY=sk-…
npm run dev              # 重启后生效
```

浏览器只调用本机接口 `/api/llm/chat`（SSE 流式），key 永不下发；接口仅限 localhost 同源访问（与 PowerPoint 桥接相同的安全规则），并有 0.8 秒冷却与每日 300 次限额。`.env` 已被 .gitignore 排除，不会提交到仓库。

### 激光笔

课件视图中比“2”保持约 0.6 秒开关激光笔（或按 L 键、点击“激光笔”按钮）。开启后手指指向显示为红色光点，替代普通手势光标；挥手翻页不受影响，两者使用独立手势。光点绘制在本工作台页面内——控制外部 PowerPoint 时它不会出现在 PowerPoint 窗口上；需要在投影大屏上指示时，请用“应用内课件”模式放映本页面。

### 语音命令

点击导航栏“语音命令”启用（Edge / Chrome，需麦克风权限）。识别到短语后转为统一交互事件执行，与手势、鼠标共用同一事件总线：**下一页 / 上一页**（仅课件视图）、**白板 / 课件 / 几何 / 函数 / 量角 / 物理 / 分子 / 背诵 / 晨昏线 / 四季 / 月相 / 地球**（切换视图）、**撤销、重置、提示、激光笔、开始 / 暂停**（仿真）；未命中的语句转交激活场景解释（找国家支持“定位+国名”，五带与四季支持节气名、五带名与“正午”，函数绘图支持“直线/抛物线/正弦”与“清除/重画”，月相仪支持四相名与“今天”，量角器支持“锁定/解锁/读数”，分子搭建支持“添加氧”“删除”“清除”）。状态栏实时显示转写与执行结果，未识别的语句只提示不执行；破坏性操作（如清空白板）不设语音入口。语音识别由浏览器语音服务完成，本应用不保存音频与转写。

### 后台摄像头与挥手判定

勾选“允许 PPT 模式下后台使用摄像头”后，切换到 PowerPoint 窗口仍继续识别，避免单屏演示时必须并排窗口。识别循环由 Web Worker 定时器驱动，不受浏览器对后台页面主线程定时器的节流影响（后台约每秒采样 10 次）。翻页方式不变，仍是挥手，因此不需要盯着屏幕也不需要用手指去够某个区域。

判定条件（`src/pptGesture.ts`，有单元测试覆盖）：横向位移至少 18% 屏幕宽、耗时 80—700ms、同向位移占比 ≥85%、上下位移不超过 18%。捏合开始时清空轨迹并在随后 0.3 秒内不判定，避免“伸手去点按钮”的移动被误认为翻页；持续捏合中不再逐帧清空，放松的手型（拇指贴近食指）也能挥手翻页。每次识别后进入 0.9 秒冷却，所以一次挥手只翻一页。离开课件视图时会清空轨迹，白板和几何里的横向拖动不会翻页。

### 单屏和双屏

未勾选后台摄像头时，浏览器隐藏到后台会停止识别以保护隐私。单屏演示建议把 PowerPoint 设置成窗口放映，与浏览器并排；全屏放映推荐双屏，一屏放映、一屏保留浏览器工作台。按 Esc 退出 PowerPoint 全屏再回到浏览器。

## 安全与隐私

- 本机接口只接受 localhost 请求，并校验同源及自定义请求头；不开放 CORS。
- PowerPoint 桥接只连接已有 PowerPoint 实例，不启动、保存、修改或关闭文稿。
- 只发送翻页/状态命令；不上传 PPT，也不保存演示画面。
- 接口对连续命令限速，防止连续挥手或抖动造成快速翻页。
- 摄像头画面只在本地推理，默认不录制、不上传。
- 语音命令显式启用；识别由浏览器语音服务完成，本应用不保存音频或转写。

如果无法连接，请确认 PowerPoint 已启动、文稿已打开并开始放映；关闭任何模态对话框。若浏览器与 PowerPoint 以不同 Windows 权限运行（例如一方“以管理员身份运行”），请改为相同权限级别后重试。
