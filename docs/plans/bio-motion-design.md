# 生物实验一 · 运动系统（bio-motion）设计方案

状态：已实现。本文档记录设计决策，供课程报告引用。

## 1. 定位与教学目标

对准八年级生物"动物的运动系统"（骨、关节、骨骼肌）：**骨架直接叠加在摄像头画面上**，屈肘/伸肘时实时显示肘关节角度与肱二头肌/肱三头肌的协作状态。直击高频迷思概念——"屈肘只有肱二头肌收缩"，正确认知是配对肌群"一收一舒"。延续平台铁律：确定性内核可单测、零新增手势词汇、任务 A/B/C、离线推理不录制。

## 2. 技术方案

### 全身姿态识别（平台层）
- `@mediapipe/tasks-vision` 自带的 **PoseLandmarker**（33 点全身关键点 + visibility），模型 `pose_landmarker_full.task`（float16，约 9MB）由 `scripts/setup-model.mjs` 下载到 `public/mediapipe/`（脚本已支持存在即跳过）；
- **`usePoseInput` 钩子与手部识别共享同一个 `<video>` 元素**——两个独立循环各自读 `currentTime` 去重后调 `detectForVideo`，不开第二个摄像头流；仅在激活场景注册了姿态策略时逐帧推理（30fps），其他场景零开销；
- 服务契约新增 `registerPosePolicy`（与 registerPolicy 同构）+ `handVideo`（共享画面引用）；GPU 失败自动降级 CPU；
- 手部识别循环保持不变——捏合点按钮、手势光标在生物场景照常可用。

### 确定性内核 `bioMotion.ts`
- `elbowAngle`：复用量角器的 `angleAt`（顶点=肘，两边=肩、腕），可见性 <0.5 拒绝；`bestElbowAngle` 自动选可见性较好的一侧（两侧都可看时选更屈的一侧——动作意图更明确）；
- `flexState`：≤100° 屈肘 / ≥160° 伸肘 / 中间半屈；
- `musclePair`：教学模型——二头收缩强度 = (160−肘角)/100 截断 [0,1]，三头肌互补；屈肘 60° → 二头 1.0/三头 0.0，伸肘 160°+ → 反向；
- `upperBodyVisible`：肩部可见 + 至少一条手臂可见 → 取景判定（不完整时提示退后）；
- 6 项单测：直角配置精确值、自动选侧、状态阈值、肌肉端点/单调性、取景判定、骨骼连接对。

## 3. 交互设计

- **叠加视图**：`drawImage(video)` 镜像绘制摄像头画面（等比 cover 映射，视频与关键点共用同一变换）→ 压暗 35% 保证骨架可读 → 青色骨线 + 关节点（与手部星座图同风格）→ 肘关节琥珀色角度弧线 + "肘关节 ≈ 87°" 标注；可开关"关节标注"（肩/肘/腕名称 chip）；
- **肌肉仪表**：侧栏两根收缩强度条（绿=收缩、灰=舒张）随肘角实时互补变化；
- **手势零新增**：读数自动实时；指向画布捏合一下=锁定/解锁（与量角器同语义，取最近读数中位数抗抖）；语音"读数/锁定/解锁"（TTS 播报肘角与肌肉状态，防自激）；
- 姿态采样不进入统一事件日志（30Hz 过密），仅任务事件（predict/submit/hint/reset）入日志。

## 4. 任务设计

| 任务 | 类型 | 判题 |
|---|---|---|
| A · 肌肉协作预测 | 迷思概念四选一 | 正确答案固定=「二头收缩·三头舒张」（教学事实）；提交后现场屈肘用肌肉仪表验证 |
| B · 屈肘 90° | 构造 | 肘角 90°±10°，稳定窗口锁定判定 |
| C · 屈伸对比 | 快照对比 | 屈肘/伸肘各保存一次（按状态去重），肌肉仪表并排 + 反思配对肌群协作 |

## 5. 测试与边界

- 内核 6 项单测 + 场景 4 项交互测试（接入/任务门控）；全量 204 项通过；
- 边界：肌肉模型为线性教学简化（不建真实肌电/力学模型）；桌前取景以动作为上肢为主（下肢关键点 visibility 低，提示退后）；单姿态（numPoses:1）；姿态采样不落事件日志；隐私沿用全局边界——本地推理、不录制、不保存画面。
