# EmbodiedEdu 课程大作业方案（讨论稿）

日期：2026-10-13。开发窗口：4—6 周，由用户确认。

本方案承接文件夹内《EmbodiedEdu · 灵境智学——总体设计方案》。当前目标为人机交互课程交付；平台扩展与科研实验属于后续阶段。本文件是建议方案，尚非最终课程要求，也不代表功能已实现。

范围修订（2026-10-13）：依据用户澄清，项目面向日常教学与多学科教学场景。PPT 控制与隔空白板是课程版的基础组成；空间几何是第一学科验证场景，不是整个项目的定位。后续学科按完成度逐步接入。

## 1. 课程版定位

建议题目：**灵境智学：面向智慧教学的多模态智能交互系统**。

核心问题：教师与学生能否通过低负担、可恢复的多模态交互，连续完成课件讲解、白板表达和学科探究？空间几何作为第一个学习任务，用于验证身体动作与知识反馈的联系。课程阶段首先验证交互可用性与任务完整性，不预先宣称学习效果提升。

交付形态：一套可本地运行的教学工作台，包含课堂工具、共享交互内核和可接入多学科的场景接口。手势承担指向、绘制与操作；建议接入小规模语音命令实现输入模态互补，鼠标/键盘承担备用输入。语音未实现时，应准确说明已有输入，不将界面多视图当成多模态。

## 2. 方案比较与选择

| 方案 | 优点 | 4—6 周内的主要代价 | 定位 |
|---|---|---|---|
| 空间几何截面探究 | 对象与结果清晰；便于设计连续操作、对照输入和确定性判定 | 截面计算、模式设计、手势稳定性 | 推荐主线 |
| 力与运动探索 | 可形成预测—实验—解释流程 | 需要解释速度、加速度、时间变化；任务范围容易扩大 | 交付后的第二场景 |
| 实体卡片/教具实验 | 真实操作感强 | 机位、遮挡、标记和现场布置增加稳定性要求 | 后续扩展 |

课程版完成日常课堂基础工具和一个完整学科场景。第二学科（简化力学）在核心功能稳定后用于演示跨学科复用；其他学科保留明确接口与规划，不用空页面宣称已完成。

## 3. 学习与演示主流程

进入教学工作台 → 检查摄像头与输入 → 打开课件并用手势翻页/指示 → 切换白板并绘制、撤销 → 打开学科场景 → 提交预测 → 操作切面 → 观察结果 → 获取分级提示 → 提交解释 → 返回课堂与回顾。

这一流程贯通教师讲解与学生探究；角色按任务模式区分即可，首版不需要复杂账号与权限系统。

任务设计：

- 任务 A：在预设切面方向下，先预测指定位置的截面边数，再移动切面验证。
- 任务 B：从不同预设姿态出发，探索三角形、四边形、五边形、六边形截面中的指定目标；任务初始状态和允许操作需保证目标可达。
- 任务 C：保存两个切面状态，比较边数或形状变化，并解释哪些面/棱参与了相交。

先完成 A、B；C 的完整对比面板可安排在第五周。基础回顾始终保留。

## 4. 必做功能

| 模块 | 实现范围 | HCI 体现 |
|---|---|---|
| 设备与入门 | 摄像头权限/状态、输入选择、短操作练习 | 可学习性、错误说明、替代路径 |
| 课件控制 | PPT/课件上一页、下一页、指针、当前模式反馈 | 情境交互、防误触、教师控制 |
| 隔空白板 | 捏合绘制、松开移动、清晰轨迹、颜色/粗细控件、撤销、清空确认 | 连续直接操作、模式可见、错误恢复 |
| 教学工作台 | 课件、白板、学科探究切换；切换时结束旧操作并保留必要状态 | 任务连续性、上下文管理 |
| 核心场景 | 一个正方体、一个切面、实时截面与二维放大视图、边数显示 | 直接操作、多视图联动、结果可见性 |
| 手势输入 | 指针、捏合抓取、移动、松开释放 | 少量一致动作、自然映射 |
| 操作模式 | 显式切换位置与方向模式；受约束地调整参数 | 避免单目三维估计和模式歧义 |
| 状态与恢复 | 目标高亮、抓取反馈、追踪状态、撤销、重置 | 反馈、容错、用户控制 |
| 教学任务 | 任务卡、预测、确定性判定、结果提交 | 以学习目标组织操作 |
| 教学提示 | 用户请求提示；对长时间停滞提供非强制提示入口 | 渐进引导、减少打断 |
| 记录与回顾 | 预测、关键操作、提示、结果、解释和任务耗时 | 过程可追溯、支持评价 |
| 备用输入 | 鼠标与界面控件完成同一任务 | 可访问性、稳定演示、实验基线 |

课件实现边界在开发时明确选择：控制指定 PowerPoint 放映窗口，或将 PPT 预转换为应用内课件。两条路径都需明确支持范围，不能将普通图片浏览宣称为任意 PPT 兼容。首版不支持课件编辑。

白板定位为图示和简短批注，优先验证直线、圆和简单箭头，不承诺隔空输入长段文字的精度，也不加入手写 OCR。

多模态最小建议：有限语音命令用于“打开白板、返回课件、撤销、暂停交互”等离散操作，手势用于连续操作。命令需要转写/执行反馈、显式启用与冲突规则；破坏性操作保留确认。若语音来不及稳定实现，应降低对已完成多模态能力的表述，而不是牺牲课堂核心功能。

截面边数是必做；面积和周长只有在算法与退化情况经过验证后才进入展示。三维场景与二维截面使用同一几何结果。

## 5. 交互设计

### 5.1 最小动作集合

- 手部移动：移动可见指针，不默认触发操作。
- 指针进入操作手柄并捏合：锁定目标、记录初始位置与参数、开始操作。
- 保持捏合并移动：根据当前模式改变一个明确参数。
- 松开：提交操作；下次抓取从新的参考位置开始。

撤销、重置、提示和模式切换首先使用大按钮与键盘快捷键，语音命令接入后复用同一事件。方向控制可用两个明确的轴模式或手柄；不把单目手掌姿态当作精确六自由度数据。双手缩放只作加分项。

模式映射：课堂模式中的翻页动作仅控制课件；白板模式中的捏合移动绘制笔迹；几何模式中的捏合移动调整切面。统一的是事件协议和状态管理，具体含义由当前场景决定。自然讲课动作不能直接触发全局翻页。

### 5.2 建议状态机

设备未就绪 → 就绪/空闲 → 悬停可操作目标 → 抓取锁定 → 连续操作 → 释放完成。

操作中追踪失效：停止更新并回退本次未提交操作，提示重新抓取；恢复追踪时不得自动续接或造成对象跳变。切换模式时先结束当前操作。

### 5.3 防误触与低负担

只在可见操作区域和目标手柄上允许抓取；捏合阈值按手部尺度归一化，并使用进入/退出不同阈值；确认时间、平滑强度依据试用调整；连续输入不做事件堆积；离开操作区不触发快捷指令。

任务短时完成，允许低幅度动作与随时切换鼠标。显示当前输入、模式和目标，避免用户猜测系统状态。

## 6. 课程创新表达

以下是本项目建议突出的交互特点，尚未经过文献查新，不表述为领域首创。

0. **教学上下文驱动的统一交互**：同一感知与交互内核贯通课件、白板和学科任务；模式可见并管理冲突。有限语音承担模式/离散命令、手势承担连续操作，形成实际模态互补。

1. **动作—几何现象联动**：切面变化同时更新三维交线、二维截面和边数；边数改变时，短暂标出新参与/退出相交的面或棱，帮助关联操作与几何变化。临界位置使用明确的容差和退化标记，避免数值噪声反复触发教学反馈。
2. **预测—验证—解释闭环**：先记录学生预测，再开放探究操作，对比预测与真实计算结果，最后要求解释。学习流程不仅是自由旋转模型。
3. **与操作过程相关的渐进提示**：根据任务规则、操作记录和预测差异选择问题或局部提示；优先让学生观察，不立即展示答案。首版使用透明规则，不依赖在线模型判断数学结果。

快照对比与变化时间线是第五、六周的优先加分功能，能够进一步体现过程反馈。

## 7. 技术边界与实现顺序

沿用总体设计中的候选技术路线：视觉感知模块 → 统一语义事件 → 场景与任务状态 → 确定性几何规则 → 界面与教学反馈。

手势和鼠标产生相同语义操作；学科代码不直接读取摄像头坐标。先用鼠标跑通完整任务，再接入摄像头，并在独立模块内处理识别和平滑。具体依赖版本和接口在实现阶段核验与锁定。

运行优先本地化；规则提示不需要联网。记录必要事件元数据，默认不录制摄像头画面。暂不加入账号系统、微服务、复杂手势训练、全部学科完整内容、实体机器人。

## 8. 时间安排

| 时间 | 核心成果 | 阶段验收 |
|---|---|---|
| 第 1 周 | 工作台流程、输入可行性、统一事件、课件控制与鼠标场景骨架 | 课件可播放/控制，摄像头可用，几何算法风险早期验证 |
| 第 2 周 | 手势翻页/指示、白板绘制/撤销、状态机与模式切换 | 能连续完成课堂基础演示，日常动作不随意触发命令 |
| 第 3 周 | 几何场景、多视图、手势操作、任务、提示与日志 | 课堂—学科—反馈流程贯通，异常可恢复 |
| 第 4 周 | 用户试用、跨模块修复、说明文档、视频与答辩材料 | 冻结基础工具和首个学科，完成可交付版本 |
| 第 5—6 周 | 有限语音命令、简化力学或快照对比、第二轮试用 | 优先验证模态互补与场景复用，加分项不降低稳定性 |

若只有四周，保留课件控制、隔空白板、共享状态管理和一个学科闭环；语音和第二学科按可行性安排。如果核心链路落后，先减少任务数量和装饰性功能，保留课堂基础、任务闭环、状态反馈、撤销和备用输入。若语音作为答辩必须展示的模态，应在第一周验证可行性并提前安排，削减第二学科与视觉装饰。

## 9. 稳定展示策略

- 提前验证机位、光照、背景与摄像头权限；页面提供设备检查与简单校准。
- 每个任务有已验证的初始状态，支持一键重置，允许直接进入指定演示任务。
- 视觉模块使用最新有效状态，避免旧输入在网络或计算延迟后继续执行。
- 设备断开、追踪失效、识别不确定和无截面都有明确界面反馈。
- 预设截面覆盖正常结果，也验证经过顶点、经过棱、与面重合和完全不相交等边界；边界不当作普通多边形强行解释。
- 学习任务和演示不依赖外部模型服务；鼠标可以独立完成全流程。
- 在答辩设备上使用同一运行环境连续演练，录制与真实版本一致的备用视频。

## 10. 验收与用户测试

建议课程验收目标，最终可随课程评分要求调整：

1. 已验证场景中的数学结果与预设参考一致，关键几何边界有明确处理。
2. 在说明的设备和环境下，连续完成 10 次核心演示流程，无崩溃、无无法恢复的卡死。
3. 遮挡手部或断开摄像头不会持续操作；恢复后需要重新抓取，场景不跳变。
4. 至少 3 名未参与开发的同学经过短说明，能够完成核心任务。
5. 默认不保存原始画面；日志能够回顾预测、操作、提示和结果。
6. 他人按 README 可以启动，鼠标输入可完成所有必做任务。
7. 课件—白板—学科场景连续切换后，旧操作不泄漏到新模式；返回时课件页码与白板内容按设计保留。
8. 可用性测试同时覆盖翻页误触、白板绘制/撤销、学科操作和模式切换。语音已接入时补充误识别、重复命令与输入冲突测试。

建议邀请 5—8 名成年同学做可用性试用，视实际招募调整。使用匹配难度的任务比较鼠标与手势，并平衡使用顺序，减少先后学习影响。记录任务成功、时间、误触、撤销、提示使用、疲劳和访谈意见；报告响应延迟与测试设备。小样本定位为形成性可用性评价，不据此宣称显著学习提升。

## 11. 答辩演示与交付

建议 3—5 分钟现场流程：

设备检查 → 教师翻页与指示 → 白板画图与撤销 → 切换几何任务 → 学生预测与手势操作 → 规则引导与修正 → 返回课件/回顾。语音和第二学科已实现时，插入一次语音切换及一次简化力学操作，说明复用关系。

答辩材料说明用户问题、设计方案、交互映射、错误处理、用户测试发现与修改。统一事件与架构另作一页解释，面向学生的界面不显示调试细节。

交付清单：源码与固定依赖、启动说明、任务与预设场景、交互流程与状态图、功能与算法验证、用户测试报告、现场演示脚本、演示视频、课程汇报材料。

## 12. 加分功能优先级

有限语音命令（如已列为多模态承诺则提前完成） → 简化力学验证或快照对比 → 更清楚的面/棱变化高亮 → 校准与疲劳优化 → 双手缩放。

创新主要依靠交互与学习流程体现；后面的功能只有在必做验收完成后才启动。
